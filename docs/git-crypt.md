# git-crypt (retired)

Strategy encryption via git-crypt on the public repo is **retired**.

Private strategy code now lives in the **CryoBacktester-workspace** submodule.
See [workspace-submodule.md](workspace-submodule.md).

If you still have `~/.cryo-backtester-git-crypt.key` from the old setup, keep it
only for reading **historical commits before the history rewrite**. It is not used
for current development.
